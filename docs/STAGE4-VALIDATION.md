- `CHROMIUM_PATH=/usr/bin/chromium SDK_DIR=/workspace/store-test-tools/sdk BASE_URL=http://127.0.0.1:8080/ node tests/live-emulator.mjs`: **15 ناجح، 0 فشل**. تغطي الوظائف السابقة وإدارة المرحلة 3، ثم القراءة من Firestore REST وصفحة المنتج وحفظ المفضلة واسترجاعها وحذفها باستخدام Firebase SDK والقواعد الحالية.

## التشغيل

شغل `python3 -m http.server 8080 --bind 127.0.0.1` من جذر الريبو. Node وPlaywright وFirebase أدوات اختبار فقط، وليست dependencies للموقع.

لاختبار Firebase استخدم المشروع المحلي `demo-store` مع Firestore Emulator على 8085 وAuth Emulator على 9099. `SDK_DIR` يحتوي الملفات الرسمية `firebase-app.js` و`firebase-auth.js` و`firebase-firestore.js` من Firebase 10.14.1. الاختبار يستبدل config داخل المتصفح، ولا يستخدم مشروع المتجر الحقيقي. صفّر بيانات المحاكيات المحلية بين التشغيلات لتجنب تكرار حسابات الاختبار.
