# التحقق من المرحلة 5

التحقق تم على بيانات محلية تجريبية وFirebase Emulator بمشروع `demo-store`، دون كتابة في `store-4cfd5`. الكوبونات TEST10 وLIVE10 وغيرها موجودة في اختبارات معزولة فقط. لم يُضف أو يُفعّل أي كوبون حقيقي.

## النتائج

- `node tools/check.mjs`: **1028 ناجح، 0 فشل**، وsyntax لـ52 ملف JavaScript. تشمل دمج كمية نفس التركيبة، وحدود المخزون والكمية، والكوبون النسبي والثابت والسقف والصلاحية والاستخدام الشخصي، والشحن بعد الكوبون، والمحافظات المقفولة، وعزل سلات الحسابات، وحفظ تعديلات نافذة ثانية، وفشل الكتابة، والمنتج المخفي.
- `CHROMIUM_PATH=/usr/bin/chromium node tests/smoke.mjs http://127.0.0.1:8080/`: **27 رحلة ناجحة**. على موبايل 390×844 وديسكتوب 1440×900، بالإضافة للإنجليزي والوضع الداكن. رحلة المرحلة 5: اختيار تركيبة → إضافة للسلة الجانبية → سلة محفوظة بعد إعادة التحميل → محافظة وكوبون → تحقق من العنوان → مراجعة الإجمالي → تسجيل حساب ودمج السلة → اختيار عنوان محفوظ → تعديل الكمية → كشف نفاد المخزون → حذف. لا أخطاء console أو خروج أفقي.
- `NODE_PATH=/workspace/store-test-tools/rules/node_modules node tests/rules.test.mjs`: **118 ناجح، 0 فشل**. تشمل سلة من 20 سطرًا والتحقق من آخر سطر، ورفض الحقول والكميات غير الصحيحة، والتوقيت أو الإصدار القديم، وحماية سلة العميل، ومنع العميل من تعديل الكوبونات أو عدادات استخدامها.
- `CHROMIUM_PATH=/usr/bin/chromium SDK_DIR=/workspace/store-test-tools/sdk BASE_URL=http://127.0.0.1:8080/ node tests/live-emulator.mjs`: **16 ناجح، 0 فشل**. تشمل Firebase Auth وREST وSDK، وحفظ واسترجاع السلة، وتطبيق كوبون تجريبي، والشحن، والمراجعة، مع استمرار اختبارات المراحل السابقة.

## تشغيل الاختبارات

شغّل السيرفر من جذر الريبو: `python3 -m http.server 8080 --bind 127.0.0.1`.

شغّل Firestore Emulator على 8085 وAuth Emulator على 9099 للمشروع المحلي `demo-store`. صفّر بيانات المحاكيات المحلية قبل كل suite، ولا تشغّل rules وlive في نفس الوقت. `SDK_DIR` يحوي ملفات Firebase 10.14.1 الرسمية. Node/Playwright/Firebase أدوات اختبارات خارج تطبيق الموقع؛ الموقع لا يحتاج npm أو build.

## الصور وحدود المرحلة

الصور المحلية غير المضافة لـGit في `tests/screenshots/`: `stage5-drawer-*` و`stage5-cart-*` و`stage5-checkout-*` و`stage5-english-dark-*` و`live-stage5-checkout.png`. تمت معاينة صور الموبايل والديسكتوب.

المراجعة **لا تنشئ طلبًا ولا تغيّر المخزون أو عداد استخدام الكوبون**، والاختبارات تتأكد من ذلك. اختبار ظهور الطلب في اللوحة وتغيير حالته مؤجل للمرحلة 6، حيث تُنفذ هذه الوظائف.

حد الشحن المجاني يُحسب بعد خصم الكوبون، حسب اختيار صاحب المتجر. الكوبون اختياري، ومع عدم وجود كود صالح لا يُخصم شيء. إنشاء وإدارة الكوبونات من اللوحة في المرحلة 10.

يلزم نسخ `firestore.rules` بالكامل إلى Firebase Console ← Firestore Database ← Rules ← Publish. لم تنشر أدوات الاختبار القواعد على المشروع الحقيقي.
